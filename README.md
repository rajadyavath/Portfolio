## 🌟 Overview & Design Philosophy

This portfolio is engineered to stand out to senior engineering leads and recruiters within the first 5 seconds. Inspired by design systems from **Apple, Stripe, Linear, Vercel, and Arc Browser**, it replaces typical static resume cards with immersive **interactive case studies, live WebGL particle matrix canvas, a Command Palette (Ctrl+K), and a CLI Terminal shell**.

---

## ⚡ Key Technical Features

1. **Cinematic Hero Landing**:
   - WebGL/Canvas interactive particle constellation reactive to mouse movement.
   - Dynamic typing role ticker (`Generative AI Microservices`, `LLM RAG Pipelines`, `Async FastAPI Systems`).
   - Floating glass metric cards showcasing 95%+ ML accuracy, 20% service delay reduction, and 10+ VR voice commands.

2. **The Engineering Narrative**:
   - Tells the narrative of transitioning from Automobile Engineering telemetry and physical systems into high-throughput software backends, FAISS vector search, and LLM fine-tuning.

3. **Deep Interactive Project Case Studies**:
   - Tabbed breakdowns for each project: *Problem Statement*, *System Architecture*, *Interactive Code Highlights*, *Engineering Challenges & Solutions*, *Performance Metrics*, and *Lessons Learned*.

4. **Technical Competency Matrix**:
   - Skill groups with visual proficiency badges across Generative AI, Backend & Distributed Systems, Spatial Computing (Unity OpenXR), Databases, and Data Structures.

5. **Developer & Recruiter Tools**:
   - **Command Palette (`Ctrl+K` / `Cmd+K`)**: Instant keyboard navigation, profile searches, and direct contact triggers.
   - **Interactive CLI Terminal**: Embedded shell allowing recruiters to run commands (`help`, `bio`, `skills`, `projects`, `sudo hire`).
   - **Live Heatmap & LeetCode Matrix**: Visual commit frequency grid and LeetCode problem counter breakdown.
   - **Spotify Now Playing Widget**: Audio visualizer depicting focus coding state.
   - **Recruiter Contact Channel**: Glass form with instant validation and copy-to-clipboard email shortcut (`rajadyavath1103@gmail.com`).

## 🛠️ Tech Stack & Architecture

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling & Theme**: Tailwind CSS with custom glassmorphic tokens, metallic gradients, dark mode default
- **Animations**: Framer Motion & Canvas 2D Mesh Rendering
- **Icons**: Lucide React
- **Typography**: Inter, Outfit, Fira Code (Google Fonts)
- **Build Performance**: 100% Static HTML Prerendering (Fast load, Lighthouse 100 benchmark ready)

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or 20.x+
- npm / pnpm / yarn

### Local Development Server

```bash
# Clone or navigate to directory
cd Portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Production Deployment

### Deploying to Vercel (Recommended)

1. Push this codebase to your GitHub repository (`github.com/rajadyavath/portfolio`).
2. Import the project into [Vercel](https://vercel.com).
3. Vercel automatically detects Next.js. Click **Deploy**.
